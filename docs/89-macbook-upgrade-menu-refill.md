| 變更 | 影響到 | 要做的事 |
|---|---|---|
| 餐飲品項可設「可續杯」；續杯照折數算（預設八折，加料也打折），品名冠「續杯・」 | 後端、前端 | migration、重 build 前端、重啟 |

| 線上點餐：客人可勾「我是續杯」，續杯不算低消（雲端已由開發機部署） | 後端（拉單、帶入結帳） | 同上 |

## 2. 升級步驟

照 docs/43 §3 的指令依序做（含前端 build）。`alembic current` 應顯示 **`c7f3a9d2e6b1 (head)`**。

## 3. 驗證（每一項都回報結果）

1. docs/43 §4 開頭的 `curl`／`launchctl` 檢查：三個 `state` 都是 `running`、兩個 http 都是 `200`。
2. 請店主用管理者帳號開「餐飲菜單」：「品項」分頁看得到「續杯折數（%）」顯示 80；編輯任一飲料看得到「可續杯」勾選。
3. 已接上正式雲端（docs/87 §3）時，勾好可續杯後按一次「發佈到線上點餐」：成功，手機開該飲料看得到「我是續杯（8 折…）」。

## 4. 出問題怎麼退

先退資料庫再退程式：`uv run alembic downgrade b5e2c8f4a1d7`（續杯設定與品項勾選會消失），
再 `git checkout <記下的 commit>`，照 docs/43 §6 重 build 前端、`install-launchd.sh`。
退版後若線上菜單還有可續杯品項，請重新發佈一次菜單（舊版發佈出去就沒有續杯）。
