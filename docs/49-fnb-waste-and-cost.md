# 49 — 餐飲損耗與成本

狀態：**已完成**（2026-10-01；F1–F4）。延續 docs/44 §3.7（每日限量）與 docs/47（餐點退款）。

## 1. 為什麼要做

O1c／O1e 上線後的三個缺口（店主 2026-10-01 問「客人吃壞、甜點放久要報廢、成本怎麼維護、報廢後有什麼影響」時查出）：

1. **客人吃壞退款時，成本被一起扣回**——等於當那份沒做過，但材料確實用掉了 → 毛利被高估。
2. **報廢只是減份數**，不進任何報表；成本也沒算。
3. **每日限量隔天自動歸零**：昨天沒賣完、沒按報廢的會默默消失，報廢統計偏低。
4. **選項沒有成本**（燕麥奶 +20 的成本無處填）→ 毛利高估。

## 3. 成本口徑

- **一份餐點的成本** ＝ 品項成本 ＋ Σ 所選選項成本。品項沒填成本＝**未知**（整份未知，不假裝是 0）；
  選項沒填成本視為 0（多數選項是「冰／熱」這種沒有額外材料的）。
- 成本在**結帳當下**凍結到明細（`sale_lines.cost_snapshot`，既有欄）；之後改成本不改寫歷史。
- **報廢／盤點短少**的成本在**按下當下**凍結到調整紀錄（`menu_stock_adjustments.unit_cost_snapshot`）。
  品項報廢用品項成本；選項（例：某支豆子）報廢用選項成本。成本未知 → 該筆損耗成本記為未知、只列份數。
- **選項的報廢是「材料損耗」，只算選項成本、不加品項成本**（Codex 對抗審查 O1f 提出，店主同意維持）：
  選項的每日限量代表材料（「藝伎豆還剩 6 杯份」），報廢的是那份豆子而不是一杯拿鐵；且同一選項群組
  可掛在多個品項上，報廢時無從得知是哪一杯。
- **客訴退款損耗**＝沒勾「還能賣」的餐點退款，其明細成本照退量比例留著不扣回（`return_lines.resellable` 落盤）。

## 4. 報表

毛利報表（`margin_breakdown`）新增：

- `food_waste_cost`：期間內餐飲損耗成本合計（報廢＋盤點短少＋客訴退款，已知成本部分）。
- `food_waste_breakdown`：三欄各自的份數與成本。
- **餐飲毛利＝餐飲已知成本營收 − 賣出成本 − 損耗成本**；全店毛利同樣扣除。
- 損耗**歸屬發生日**（報廢按下的那天、退款成立那天），與退貨扣減同口徑。

報表頁「餐飲」區塊多一張「餐飲損耗」表：依原因、依品項列份數與成本。

## 5. 關帳提醒

現金對帳頁「結帳（關帳）」時，若今天還有每日限量份數剩餘：列出「戚風 剩 2 份」等，預設全勾「報廢」；
送出關帳前先把勾選的記成報廢（一次批次 API，冪等），取消勾選的不動（隔天歸零、不記損耗——
店員明天開店填份數時自行把它算進去）。報廢失敗不擋關帳，但要明講。
