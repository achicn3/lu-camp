## 3. 收掉卡住的兩筆（2026-10-01 撞號的 #4、#5）

這兩筆交易都**已作廢**，升級後只要各送一次，系統會向平台確認是撞號、自動收成「作廢、不開立」。
平台那邊**只會被查詢，不會開出任何發票**。

1. 先確認兩筆交易真的都已作廢（`VOID_PENDING`）：
   ```bash
   set -a; source .env; set +a
   psql "${DATABASE_URL/postgresql+asyncpg/postgresql}" -c \
     "select id, sale_id, status from invoices where id in (4,5)"
   ```
   **任何一筆不是 `VOID_PENDING` 就停下來問店主**——那筆送出去會真的開立一張發票。
2. 請**店主**打開「發票待處理」頁（需要處理），對這兩列各按一次「立即送出」
   （畫面會跳出「真的開立」的確認，因為頁面不知道交易已作廢；按確定即可）。
3. 兩列都應變成「已中止」，平台回覆欄寫著「…且發票已作廢——取消開立」。
