# ADR-031：餐飲（內用／外帶）可用購物金折抵

- 狀態：已採納（店主裁示 2026-10-09）
- 相關：docs/16（購物金）、docs/35、docs/47 §2、ADR-029

## 背景

原本餐飲（`line_type == MENU`，內用與外帶都算）一律不可用購物金折抵：結帳時購物金上限是
「總額 − 餐飲小計」，低消門檻也只看非餐飲消費。店主決定拿掉這條限制。

## 決定

1. **結帳**：購物金可折抵整筆（含餐飲），試算的 `store_credit_max` 改回 `total`（欄位保留，合約不變）。
   餐飲**照舊不累點、不套門市活動**——只拿掉購物金這一條。
2. **低消門檻** `store_credit_min_spend`：改看**整筆消費**（餐飲也算），不再只看非餐飲。
3. **購物金算在哪些品項上（退款與發票同一口徑）**：購物金**先算在非餐點品項上**，最多到它們的小計；
   超出的部分才算付在餐點上。
   - 退款（`returns._refund_allocations`）：二手、餐點各自在自己那份購物金內「購物金優先」，其餘退外部付款。
   - 發票（扣掉購物金後開，`amego._invoice_line_amounts`）：購物金先依比例攤到非餐點品項，超出的才攤到餐點。
4. 餐點的退貨同意仍可用「點選同意」（docs/47 E3），與付款方式無關，不變。

## 取捨

- 「購物金先算在非餐點上」而不是全車按比例：2026-10-09 以前的單購物金必定 ≤ 非餐點小計，
  照這個口徑餐點那份購物金是 0——舊單的退款與待開發票**完全照舊**，不會把當初付的現金退成購物金，
  也不需要資料遷移。按比例分攤則會讓舊單的餐點退款改退購物金。
- 不另開設定切換：店主要的是直接拿掉限制。若日後又要限制，需另一項裁示。
