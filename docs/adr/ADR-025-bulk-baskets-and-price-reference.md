# ADR-025：歷史估價參考與散裝共用販售籃

日期：2026-09-22。狀態：已實作（2026-09-23，分支 feat/bulk-baskets），尚未合併。

## 店員操作

選定品牌、型號後自動顯示歷史收購價與上架售價區間；只看同型號、不分成色
（店主 2026-09-22 裁示），各成色明細收在可展開的表格。顯示筆數與查詢期間。
既有 API 的上架價來自各商品目前記錄的標價，不冒充實際成交價或首次上架快照。
參考值不覆蓋店員輸入；無資料／讀取失敗均不阻擋收購。

對使用者顯示的「散裝批」統一為「散裝」，「散裝批號」改「散裝編號」。
底層既有批次編號與資料欄位維持相容。

收購散裝時可建立販售籃，或明確選擇加入已有販售籃。無品牌可留白。
第一版採同品項、同每件售價整批加入，不依文字相似度自動合併。
不同材質、尺寸、狀況需由店員決定是否為同一販售品項。
同籃沿用名稱、品牌、分類、單價及永久條碼；補貨後可沿用原標籤。
籃售價可統一調整，需提醒重新列印標籤；不改動已成交的價格與成本。

## 來源與販售分開

- `BulkLot` 保留每次收購的來源、成本、數量與原收購單，不跨賣方覆寫或合併。
- 新增 `BulkBasket` 作為販售品項，原來源可掛 nullable `basket_id`。
- 可用庫存由有效來源剩餘量加總，不維護第二份容易失去同步的數量。
- 第一版僅支援自有散裝；不將寄售混入，不支援單一來源拆到多籃。
- 舊資料不自動改組；整批加入必須驗證門市、所有權、售價與來源狀態。
- 舊来源條碼若已入籃，POS 導到同一籃；來源不能繞過籃子獨立改售價。

例：甲收 10 支營釘、總成本 50 元；乙收 20 支、總成本 160 元。
籃子顯示 30 支，同一張條碼。賣 12 支，後台分配甲 10 支、乙 2 支，
剩餘 18 支；保留原始來源，不能把總收購成本直接加到單件收購價。

散裝估價區間以同籃的每來源「總成本 ÷ 原數量」計算單件參考，
採 Decimal 與整數元 HALF_UP，明示是單件估價；樣本數為來源收購筆數。

## 結帳與回補

購物車、報價、折扣索引、客顯及簽署保持一籃一行。拒絕將原請求直接拆成多行，
避免破壞既有各系統的一對一對應。

`SaleLine` 增加籃關聯（`bulk_basket_id`），另以 `SaleBulkAllocation` 記錄來源 lot、數量、
成本快照與已退數量。籃子行的 `bulk_lot_id` 填第一筆分配作為「代表來源」：同籃來源的
品牌／分類必與籃子一致、且只收自有散裝，所以既有報表依 `bulk_lot_id` join 品牌／分類／寄售人
的查詢不會漏掉籃子行；**庫存回補與成本一律依分配紀錄，不看代表來源**。後端同一交易中固定順序鎖定來源，再依入庫時間及 ID FIFO 分配。
籃子交易與直接來源交易競爭相同庫存；缺貨整筆回滾，不容許負库存。
重試指紋依原始請求，不使用會隨庫存變化的分配結果。

退貨及銷售作廢按原分配回補來源，累計回補不得超過售出數量。
回補順序固定為「後分配的先回」（`sales/bulk_allocation.py`）：同一個累計退貨量永遠對應
同一組各來源回補量，報表的成本反轉也用同一個函式逐來源計算（差額法），
帳上成本因此等於回到各來源的庫存價值。
收購作廢僅處理該次來源，不能移除其他來源或整個籃子。
銷售成本、報表及來源查詢必須使用成交快照與分配關聯，不可漏算籃子行或重複算庫存。

## 分工與驗收

1. 歷史價格提示：獨立前端元件與測試，沿用現有 API。
2. 散裝文案：獨立文字調整及定位測試，不更動 DB 名稱。
3. 散裝後端：依序完成籃管理、收購入籃、分配結帳、退款／作廢／報表。
4. 散裝前端：依已生成 API 完成收購選籃、庫存管理與標籤、POS 掃碼及購物車還原。
5. 主代理整合：合約重產、獨立審查、真 PostgreSQL 與瀏覽器驗證。

必驗：兩次收購共籃、跨來源銷售、部分退貨、來源作廢、並發庫存不足、
跨店隔離、報價與結帳一致、折扣與贈品、冪等重試、舊標籤、價格快照、手機操作。
未通過完整金額／庫存驗證前，不部署或以「只換標籤」方式提前啟用。

## 實作備註（2026-09-23）

- 標籤碼 `K{店}-{10 碼 HEX}`，與 `S`／`L` 同一套 Code 128 字元集；POS 掃到 `K` 碼直接查籃子。
- 籃子的名稱、品牌、分類、每件售價同步到籃內來源（改籃價即改來源價，含已售完、日後退貨會回來的那批）；
  入籃的來源不能單獨改這四項（409）。既有散裝「加入籃子」須同價、自有、未入其他籃。
- 收購可「開新販售籃」或「加入現有販售籃」（後者名稱／品牌／分類／售價以籃子為準）；
  兩欄位沒帶時冪等指紋維持舊形狀。加入既有籃不必重印標籤。
- 經營洞察的散裝成本改優先取成交成本快照（與毛利報表同口徑），否則籃子行會用代表來源重算而失真。
- 還原演練新增兩項檢查：販售籃數、分配紀錄的件數／已退／成本合計。
