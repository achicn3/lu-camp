# ADR-026：收購選品作廢與全額購物金不開票

日期：2026-09-29。狀態：依門市使用者確認實作。

## 背景

收購可能只退回幾件；整單作廢會誤動其他庫存與款項。門市另外指定全額購物金消費不開票。

## 決定

- 買斷收購新增選品作廢，維持原單與原入帳；每次作廢另存事件與已作廢商品 ID。
- 原付款比例與原實發購物金是分攤基準，以累計金額差額處理整數尾差。全部商品作廢才關閉原單。
- 購物金分錄仍是追加式，選品沖正綁唯一事件；銷售整筆沖正與歷史收購沖正保留原有防重規則。
- 全額購物金銷售不建立 Invoice、上傳佇列或呼叫平台。銷售總額及 tender 維持實際成交值，
  `invoice_status=NOT_ISSUED`。混合付款與既有已開發票不變。此為本次門市開票政策裁示。
- 客顯解除配對後自動產生配對碼，過期自動更新，網路失敗自動重試。短暫離線保留裝置身分及配對。
  不提供客人可點擊的解除或刷新配對按鈕，解除動作仍在有員工權限的 POS。

## 影響與驗證

新增 migration `f8c4d2a91b63`；已有選品作廢紀錄時拒絕降版，避免刪除歷史帳目。
整合測試覆蓋分次沖回、尾差、餘額不足回滾、報表及並發防重；前端測試和真實瀏覽器煙霧
覆蓋勾選確認與客顯解除後自動取碼重新配對。
