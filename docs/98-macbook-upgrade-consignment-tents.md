## 3. 驗證（每一項都回報結果）

1. docs/43 §4 開頭的 `curl`／`launchctl` 檢查：三個 `state` 都是 `running`、兩個 http 都是 `200`。
2. 請店主開「更多 → 官網寄售帳篷」：看得到在庫的寄售品清單，最上方是「官網已同步」或「有變更還沒上官網」，
   **不是**「尚未設定線上點餐雲端」也**不是**「官網更新失敗」。
3. 請店主挑一頂帳篷按「編輯」→ 勾「上架官網」→「儲存」，約 1 分鐘內打開
   https://lukeng-camp.com/tents.html 看得到這頂（官網要先部署，見 docs/97 §7）。不想留在官網就再取消勾選。
